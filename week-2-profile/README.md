# Responsive Semantic Profile Page

A personal profile portfolio page built for the Week 2 frontend development assignment. It extends the Week 1 semantic HTML page with a mobile-first responsive layout.

## Features

- Semantic page structure using `header`, `nav`, `main`, `section`, `article`, and `footer`
- In-page navigation links to the About, Learning Goals, Tech Spotlight, and Contact sections
- Personal profile photo with descriptive alternative text
- Three frontend learning goals in an unordered list
- A QGIS tech spotlight article
- Copyright information and external GitHub and LinkedIn links
- A single-column mobile layout, two-column tablet layout, and three-column desktop layout
- Mobile-first CSS with `min-width: 768px` and `min-width: 1024px` media queries
- Fluid images and responsive units to prevent horizontal overflow
- External stylesheet in `styles.css`, linked from the HTML page
- Profile photo stored in the `assets/` folder

## Run the project

1. Download or clone this repository.
2. Open the `week-2-profile` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension to preview the page.

## Responsive testing

The `screenshots` folder contains browser captures of the page at the required viewport widths:

- Mobile: 375px
- Tablet: 768px
- Desktop: 1024px
