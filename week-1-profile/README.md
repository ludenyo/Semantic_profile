# Semantic Profile Page

A personal profile portfolio page built for the Week 1 frontend development assignment. The project uses semantic HTML5 and a small amount of CSS for a clean, responsive layout.

## Features

- Semantic page structure using `header`, `nav`, `main`, `section`, `article`, and `footer`
- In-page navigation links to the About, Learning Goals, Tech Spotlight, and Contact sections
- Personal profile photo with descriptive alternative text
- Three frontend learning goals in an unordered list
- A QGIS tech spotlight article
- Copyright information and external GitHub and LinkedIn links

## Project structure

```text
week-1-profile/
├── index.html
├── favour-ludenyo.jpeg
└── README.md
```

## Run the project

1. Download or clone this repository.
2. Open the `week-1-profile` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension to preview the page.
